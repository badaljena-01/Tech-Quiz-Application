# Java Quiz System

A desktop-based **Java Quiz System** developed using **Java Swing** and **AWT**. The application provides an interactive graphical user interface where users can log in, read quiz instructions, answer timed multiple-choice questions, use a one-time 50-50 lifeline, and receive an automatically calculated final score.

---

## 📌 Project Overview

This project is designed to demonstrate Java GUI development using Swing. It follows a multi-screen workflow and incorporates event handling, timers, radio buttons, object-oriented programming concepts, and score evaluation.

---

## ✨ Features

- 👤 User Login Screen
- 📋 Quiz Rules Page
- ❓ 10 Java Multiple Choice Questions
- ⏱️ 15-Second Countdown Timer for Each Question
- 🎯 One-Time 50-50 Lifeline
- ➡️ Next and Submit Navigation
- 📊 Automatic Score Calculation
- 🔄 Play Again Option
- 🖥️ User-Friendly Graphical Interface

## 🚀 How to Run

1. Clone the repository.
2. Open the project in NetBeans, IntelliJ IDEA, or Eclipse.
3. Ensure the **icons** folder is available in the project's resources.
4. Run `Login.java`.
5. Enter your name and start the quiz.
